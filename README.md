# Decision Tree Visualizer

Interaktive Browser-Lernapp für **Entscheidungsbäume / Decision Trees**.

## Inhalte

- Splits und Entscheidungsbereiche visuell verstehen
- Baumtiefe interaktiv verändern
- Rauschen und Datenmenge anpassen
- Trainings-Accuracy beobachten
- Anzahl Blätter und gelernte Tiefe sehen
- Vereinfachte Baumdarstellung
- Eigene Punkte klassifizieren und den Entscheidungsweg sehen
- Hell-/Dunkelmodus
- Kein Quiz
- Keine Installation nötig

## Start

Einfach `index.html` öffnen oder über GitHub Pages bereitstellen.

## GitHub Pages

Repository → **Settings** → **Pages** → **Deploy from a branch** → `main` → `/ (root)` → **Save**

Danach ist die App typischerweise unter

`https://uisy.github.io/decision-tree-visualizer/`

erreichbar.
