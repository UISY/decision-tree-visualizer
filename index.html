SCHRITT 1

Was macht ein Entscheidungsbaum?

Ein Entscheidungsbaum stellt nacheinander einfache Fragen wie „Ist x₁ kleiner als 0,7?“. Dadurch werden die Daten Schritt für Schritt in immer kleinere Bereiche aufgeteilt, bis eine Klasse vorhergesagt wird.

Split

Eine Frage teilt die Daten in zwei Gruppen.

Knoten

Jeder Knoten enthält eine Regel oder Entscheidung.

Blatt

Am Ende steht die vorhergesagte Klasse.

Baumtiefe ist wichtig: Ein sehr flacher Baum kann zu einfach sein. Ein sehr tiefer Baum kann Trainingsdaten zu stark auswendig lernen und dadurch overfitten.

📊 So teilt der Baum den Raum

Die farbigen Hintergründe sind die Entscheidungsbereiche. Die gestrichelten Linien zeigen die Splits.

🌿 Vereinfachter Baum

Warum kann ein tiefer Baum problematisch sein?

Mit mehr Tiefe kann der Baum sehr spezielle Regeln lernen. Das erhöht oft die Trainingsgenauigkeit, kann aber dazu führen, dass neue Daten schlechter vorhergesagt werden. Das nennt man Overfitting.
